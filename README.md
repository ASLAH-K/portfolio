# 🚀 Personal Portfolio — Muhammed Aslah K

A modern, fast, and fully responsive **cybersecurity-focused portfolio website** built using **React, Vite, and Tailwind CSS**.  
This portfolio showcases my projects, skills, certifications, internships, and achievements, with a clean UI and smooth animations powered by Framer Motion.

## 📌 Features

- ⚡ **Ultra-fast performance** using Vite
- 🎬 **Smooth animations** using Framer Motion
- 🎨 **Modern UI** with Tailwind CSS
- 👋 Fullscreen **Welcome Section**
- 🙋‍♂️ Interactive **Hero Section** with profile image
- 🛡 Cybersecurity-focused **Skills** section
- 🧪 **Experience & Achievements** timeline
- 🎓 **Certifications** section
- 💻 **Featured Projects** with GitHub links
- 📩 Fully working **contact form** powered by FormSubmit
- 📄 **Download Resume** button
- 🌗 Completely responsive for all devices
